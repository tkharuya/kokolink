ここリンク / KokoLink 1.0.0
Android 11以降向け・個人利用版
作成日: 2026-11-14 (日本時間)

目的
相手が地図を開いたときに更新要求を送り、送信側が必要なときだけ
短時間の測位を行う位置共有アプリです。常時のGPS追跡は行いません。
広告、アカウント登録、独自サーバーの契約、APIキーの入力は不要です。

使い始め方
1. 共有する2台へ同じ kokolink-1.0.0-personal.apk をインストールします。
2. 両方の端末で「共有をはじめる」を押し、自分の名前と同意を設定します。
   位置情報は「アプリの使用中」、通知は許可します。
   「おおよその位置」でも動きますが誤差は大きくなります。
3. 片方の端末で右上の追加ボタンから「招待を作る」を押します。
4. もう片方へ招待を送り、相手は追加画面の招待欄へ貼り付けます。
   QRまたは招待リンクでアプリを開くこともできます。
5. 相手が申請したら、両方の画面の8桁の認証番号が一致するか確認し、
   招待した側が「共有を承認する」を押します。招待は15分間有効です。
6. 地図を開くと相手へ更新を要求します。「更新」でも要求できます。
   同じ相手への連打は15秒以内、画面を開いたときの要求は60秒以内ならまとめます。
   常時の自動再測位は行いません。

省電力設定
初期設定「省電力」:
  GPSを起動せず、Wi-Fi・基地局等のネットワーク測位を最長15秒使用。
  5分以内の取得済み位置はそのまま再利用します。
「バランス」:
  ネットワーク測位を先に試し、不十分ならGPSも使用。全体で最長15秒。
  2分以内の位置を再利用します。
「精度優先」:
  正確な位置の権限があればGPSを最長20秒使用します。
  1分以内で誤差100m以内の位置は再利用します。
  正確な権限がなければネットワーク測位へ戻ります。

・測位時間、精度、前回の位置の古さは区別して表示します。
・取得に失敗したときの再試行は最短1分後です。
・複数の相手から同時に要求されたときは測位を共有します。
・移動履歴は残しません。最新の1地点と最近の共有操作だけを保持します。
・測位回数等は表示しますが、未測定の電池消費率は表示しません。

受信方式
標準:
  ntfy.shとのHTTPSストリーム接続を1本維持し、要求を受信します。
  定期的にGPSを動かす方式ではありません。通信接続の電力は消費します。
  再接続時には新しいメッセージだけを取得し、障害時は間隔を広げます。

外部プッシュ（追加の省電力設定）:
  設定の「外部プッシュで待機電力を減らす」からntfyのGoogle Play版を
  インストールし、アプリが開く購読を追加します。
  ntfyで通知を許可し、Instant delivery（即時配信）をオフにします。
  ここリンクへ戻り「連携をテスト」を実行します。
  外部アプリから実際の受信を確認できた場合だけ切り替わります。
  アプリ画面を閉じている間の専用ストリームを止め、ntfyのFCM受信を利用します。
  F-Droid版や即時配信をオンにした状態では、同じ省電力効果は期待できません。
  画面表示中のテスト成功は、スリープ中の即時性を保証するものではありません。

Androidの制約
・共有中は停止ボタン付きの通知を表示します。
・「常に許可」の位置情報権限は要求しません。アプリ画面から開始した
  location型フォアグラウンドサービスで測位します。
・深いスリープ、メーカー独自の制限、電波・サーバーの状況で遅延します。
・再起動、強制停止、OSによるプロセス終了後はアプリを開いて再開します。
  プロセス終了後の自動復帰はこの版では実装していません。
・電池を最優先するならOSの電池最適化を維持します。即時性を優先して
  制限を緩めた場合の消費増加は端末により異なります。
・送信側の画面が閉じていてもサービスが動作し通信が通れば応答しますが、
  毎回必ず即時に現在地が返るという意味ではありません。

共有の停止
全体を止める: 地図の「停止」または共有通知の「共有を停止」。
相手ごとに止める: 相手の「…」→「この相手への送信を停止」。
関係を消す: 相手の「…」→「共有を解除して削除」。
停止後の新規位置送信を止めます。送信中の通信や相手が受信済みの位置を
取り消したり、相手の端末から確実に消去したりすることはできません。
このアプリの画面を開いているときは、共有停止中も受信・承認操作ができます。

データと外部サービス
・位置と要求の本文は、ECDH P-256 / HKDF-SHA256で交換した相手別の鍵と
  AES-256-GCMで暗号化します。中継サーバーへ平文の座標は送りません。
・ntfy.shは暗号文を一時保存します。IPアドレス、通信時刻、トピックなどの
  メタデータまでは秘匿されません。
・無料中継には現在250件/日の送信上限等があります。要求・返答・承認も
  各1件です。同じIPを利用する端末の通信の影響も受けます。
  上限時はエラーを表示します。アプリ独自の利用日数制限はありません。
・標準の中継先は固定です。大人数での常用や独自の可用性保証が必要なら、
  自前中継または独自Firebase構成への拡張が必要です。この版に未接続の
  Firebase設定ファイルやダミーのサービスは含めていません。
・地図はOpenStreetMapです。表示した地図範囲とIPは地図配信元に伝わります。
  表示タイルは7日間キャッシュし、先読み・一括保存はしません。
・端末内の接続鍵と位置はAndroid KeystoreのAES鍵で暗号化します。
  バックアップ・端末間移行は無効です。再インストールすると再招待が必要です。
・連絡先、電話番号、写真、端末固有IDへのアクセスはありません。

検証の範囲
同梱 docs/validation.txt を参照してください。
APKのコンパイル・署名、暗号化/承認/停止ロジック、画面操作、実際の中継への
暗号化テストデータ送受信を確認しています。
実機2台でのAndroidサービス動作、GPS実測、スリープ中の外部プッシュ、
電池消費率の測定は未実施です。

開発者向け
・Java + Android標準API、Android 11(API30)以降、target/compile SDK35。
・ローカルWebView UI。Leaflet 1.9.4 / qrcode-generator 1.4.4を同梱。
・外部JavaScriptや解析SDKは読み込みません。JSブリッジはローカル画面のみ。
・Android Studioでこのフォルダを開いてGradle同期し、APKをビルドできます。
  Gradle 8.9 / JDK17以降 / Android Gradle Plugin8.7.3を想定。
・署名付き更新には既存の更新用鍵が必要です。署名鍵はソースZIPに含めません。
・tools/build.py はSDK Build Tools35系とECJによる依存ダウンロード不要の
  ビルド経路です。必要なパスは --help で確認できます。
・tests/run_jvm.py: 本番のEngine/Protocolを対象に、Android層と中継を代替した
  承認・停止・再送・暗号化のテストです。
・tests/ui_test.py: Chromium / Playwrightを使い、Native境界と地図タイルを
  代替した画面操作テストです。BROWSER_EXECUTABLEでブラウザを指定できます。
・tests/live_relay_test.py: 実際のntfy.shへ暗号化した合成メッセージを1件送る
  明示実行のテストです。ユーザーの実位置を送信しません。

主要ファイル
Engine.java        同意、招待、暗号化通信、共有状態、要求の抑制
Protocol.java      ECDH / HKDF / AES-GCM、期限・位置検証
Fixer.java         タイムアウト付き単発測位、キャンセル
ShareService.java  明示的な共有中通知とフォアグラウンドサービス
Relay.java         HTTPS送受信、復帰、バックオフ
Vault.java         Android Keystoreによる端末内暗号化
MainActivity.java  権限、ローカルUIブリッジ、外部アプリ連携
TileCache.java     表示タイルのキャッシュ
App.java           外部プッシュ受信、通信復帰の検出
